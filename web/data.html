② การรวมข้อมูลสถานีจากหลายแหล่ง

สถานีอุตุนิยมวิทยาแห่งเดียวกันมีข้อมูลจาก 3 แหล่ง ได้แก่ API ของกรมอุตุนิยมวิทยา NOAA GHCNh และ NOAA GSOD ระบบรวมทั้งสามแหล่งไว้ที่จุดเดียวกันเพื่อให้ได้อนุกรมเวลาต่อเนื่องตั้งแต่ปี 2543 โดยมีหลักการดังนี้

  1. จุดเดียวกัน (รหัส WMO) — รหัสสถานี GSOD/ISD ประกอบด้วย USAF 6 หลัก + WBAN 5 หลัก เช่น 484550-99999 เมื่อ USAF ลงท้ายด้วย 0 และ WBAN เป็น 99999 ตัวเลข 5 หลักแรกคือรหัส WMO ของกรมอุตุนิยมวิทยา จึงบันทึกเป็น site_id = tmd:48455 เช่นเดียวกับ API ของกรม ส่วน GHCNh ใช้รหัส WMO ที่ระบุในรายชื่อสถานี (สถานีที่ไม่มีรหัส WMO ใช้ ghcnh:<ID> หรือ gsod:<ID>) · ตรวจเมื่อ ต.ค. 2569: สถานี GSOD ปี 2543 ทั้ง 66 สถานี และปี 2567 จำนวน 121 จาก 132 สถานี ตรงกับสถานีปัจจุบันของกรม
  2. ช่วงเวลาเดียวกัน — วันของ GSOD (00–24 UTC) เท่ากับวันอุตุนิยมวิทยาของไทย 07:00–07:00 น. ซึ่งเป็นช่วงของสรุปรายวันของกรม ทุกแหล่งบันทึกเวลาเป็น UTC ณ ปลายช่วง พร้อมความยาวช่วง (period_h) เช่น ฝน 24 ชม. ถึง 07:00 น. วันที่ 24 = time 00:00Z วันที่ 24, period_h 24
  3. ตัวแปรและหน่วยเดียวกัน — แปลงเป็นหน่วย SI ก่อนบันทึก (ตารางด้านล่าง)
  4. เก็บทุกแหล่ง แล้วเลือกค่าเดียวเมื่อใช้งาน — คีย์หลักของตาราง observation รวม source_id จึงตรวจสอบย้อนกลับได้ว่าค่ามาจากแหล่งใด ส่วน view observation_best เลือกค่าเดียวต่อสถานี–เวลา–ตัวแปร–ช่วงสะสม ตามลำดับ กรมอุตุนิยมวิทยา → GHCNh → GSOD (ค่าจาก API ของกรมกับ GHCNh ในช่วงที่ซ้อนกันตรงกัน ~99%)

ข้อควรระวัง

  • ฝนรายวันของ GSOD: สถานีไทยไม่ส่งรายงานฝนในวันที่ฝนไม่ตก (flag I) ระบบถือเป็น 0 มม. — ตรวจกับ CHIRPS ปี 2567 (40 สถานี) วัน flag I มีฝน > 5 มม. ใน CHIRPS เพียง 5.6% เทียบกับ 45% ของวันที่มีรายงาน · ค่าที่ไม่ครบวัน (flag A, B, C, E, H) ถูกตัดออก
  • อุณหภูมิสูงสุด/ต่ำสุดของ GSOD คำนวณจากรายงานรายชั่วโมงหรือราย 3 ชม. ส่วนของกรมได้จากเทอร์โมมิเตอร์สูงสุด–ต่ำสุดโดยตรง ค่าของ GSOD จึงอาจต่างเล็กน้อย
  • ค่าเฉลี่ยรายวันของ GSOD ใช้เฉพาะวันที่มีการตรวจวัด ≥ 4 ครั้ง · ค่าของ GHCNh ใช้เฉพาะที่ผ่านการควบคุมคุณภาพ
  • จำนวนสถานีเปลี่ยนตามปี: GSOD 66 สถานี (2543) → 133 สถานี (2553) · GHCNh 46 → 101 → ~160 สถานี

③ รอบการประมวลผลของแบบจำลองพยากรณ์

ข้อมูลจาก metadata ของ Open-Meteo (ปรับปรุงทุกชั่วโมง) · ล่าช้า = เวลาที่รอบล่าสุดพร้อมใช้งาน − เวลาเริ่มต้นของรอบ · แบบจำลองที่ไม่มี metadata ใช้ค่าประมาณ

④ แผนที่เครือข่ายสถานี

เงื่อนไขการใช้และการอ้างอิง

  • ข้อมูลแต่ละชุดอยู่ภายใต้สัญญาอนุญาตของหน่วยงานต้นทาง (ระบุในตารางข้างต้น) การเผยแพร่ต่อหรือใช้ในงานวิจัยควรอ้างอิงหน่วยงานต้นทางตามเงื่อนไขนั้น
  • ข้อมูลพยากรณ์จาก Open-Meteo ใช้ได้เฉพาะงานที่ไม่ใช่เชิงพาณิชย์ และต้องแสดงที่มา “Weather data by Open-Meteo.com” (CC BY 4.0)
  • ผลพยากรณ์เป็นผลจากแบบจำลองเชิงตัวเลข มิใช่ประกาศอย่างเป็นทางการของหน่วยงานใด
