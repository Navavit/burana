② รวมข้อมูลสถานีจากหลายแหล่งMerging station data from several sources

สถานีอุตุนิยมวิทยาแห่งเดียวกันมีข้อมูลจาก 3 แหล่ง คือ API ของกรมอุตุนิยมวิทยา, NOAA GHCNh และ NOAA GSOD ระบบรวมทั้งสามแหล่งไว้ที่สถานีเดียวกัน เพื่อให้มีข้อมูลต่อเนื่องตั้งแต่ปี 2543 ตามหลักนี้

The same weather station has data from 3 sources: the Thai Meteorological Department API, NOAA GHCNh and NOAA GSOD. The system joins all three at one station to get a continuous record since 2000, as follows

  1. สถานีเดียวกัน (รหัส WMO) — รหัสสถานี GSOD/ISD คือ USAF 6 หลัก + WBAN 5 หลัก เช่น 484550-99999 ถ้า USAF ลงท้ายด้วย 0 และ WBAN เป็น 99999 ตัวเลข 5 หลักแรกคือรหัส WMO ของกรมอุตุนิยมวิทยา จึงบันทึกเป็น site_id = tmd:48455 เหมือนกับ API ของกรม ส่วน GHCNh ใช้รหัส WMO ในรายชื่อสถานี (สถานีที่ไม่มีรหัส WMO ใช้ ghcnh:<ID> หรือ gsod:<ID>) · ตรวจเมื่อ ต.ค. 2569: สถานี GSOD ปี 2543 ทั้ง 66 สถานี และปี 2567 จำนวน 121 จาก 132 สถานี ตรงกับสถานีปัจจุบันของกรม
  2. ช่วงเวลาเดียวกัน — 1 วันของ GSOD (00–24 UTC) เท่ากับวันอุตุนิยมวิทยาของไทย 07:00–07:00 น. ซึ่งเป็นช่วงเดียวกับสรุปรายวันของกรม ทุกแหล่งบันทึกเวลาเป็น UTC ที่ ปลายช่วง พร้อมความยาวช่วง (period_h) เช่น ฝน 24 ชม. ถึง 07:00 น. วันที่ 24 = time 00:00Z วันที่ 24, period_h 24
  3. ตัวแปรและหน่วยเดียวกัน — แปลงเป็นหน่วย SI ก่อนบันทึก (ตารางด้านล่าง)
  4. เก็บทุกแหล่ง แล้วค่อยเลือกค่าเดียวตอนใช้ — คีย์หลักของตาราง observation มี source_id จึงย้อนดูได้ว่าค่ามาจากแหล่งไหน ส่วน view observation_best เลือกค่าเดียวต่อสถานี–เวลา–ตัวแปร–ช่วงสะสม ตามลำดับ กรมอุตุนิยมวิทยา → GHCNh → GSOD (ค่าจาก API ของกรมกับ GHCNh ในช่วงที่ซ้อนกันตรงกัน ~99%)
  1. Same station (WMO code) — a GSOD/ISD station ID is 6-digit USAF + 5-digit WBAN, e.g. 484550-99999. When USAF ends in 0 and WBAN is 99999, the first 5 digits are the TMD WMO code, so it is stored as site_id = tmd:48455, the same as the TMD API. GHCNh uses the WMO code in its station list (stations without a WMO code use ghcnh:<ID> or gsod:<ID>) · checked Oct 2026: all 66 GSOD stations of 2000, and 121 of 132 in 2024, match current TMD stations
  2. Same time period — a GSOD day (00–24 UTC) equals the Thai climate day 07:00–07:00, the period of the TMD daily summary. Every source stores time in UTC at the end of the period, with its length (period_h), e.g. 24-hour rain to 07:00 on the 24th = time 00:00Z on the 24th, period_h 24
  3. Same variables and units — converted to SI units before storing (table below)
  4. Keep every source, choose one value when using it — the primary key of observation includes source_id, so you can always trace where a value came from. The view observation_best picks one value per station–time–variable–period in the order TMD → GHCNh → GSOD (TMD API and GHCNh agree ~99% where they overlap)

ข้อควรระวังCaveats

  • ฝนรายวันของ GSOD: สถานีในไทยไม่ส่งรายงานฝนในวันที่ฝนไม่ตก (flag I) ระบบถือเป็น 0 มม. — ตรวจกับ CHIRPS ปี 2567 (40 สถานี) วัน flag I มีฝน > 5 มม. ใน CHIRPS เพียง 5.6% เทียบกับ 45% ของวันที่มีรายงาน · ค่าที่ไม่ครบวัน (flag A, B, C, E, H) ถูกตัดออก
  • อุณหภูมิสูงสุด/ต่ำสุดของ GSOD คิดจากรายงานรายชั่วโมงหรือทุก 3 ชม. ส่วนของกรมวัดจากเทอร์โมมิเตอร์สูงสุด–ต่ำสุดโดยตรง ค่าของ GSOD จึงอาจต่างเล็กน้อย
  • ค่าเฉลี่ยรายวันของ GSOD ใช้เฉพาะวันที่วัดอย่างน้อย 4 ครั้ง · ค่าของ GHCNh ใช้เฉพาะที่ผ่านการตรวจคุณภาพแล้ว
  • จำนวนสถานีเปลี่ยนตามปี: GSOD 66 สถานี (2543) → 133 สถานี (2553) · GHCNh 46 → 101 → ~160 สถานี
  • GSOD daily rain: Thai stations send no rain report on dry days (flag I), which the system treats as 0 mm — checked against CHIRPS for 2024 (40 stations): only 5.6% of flag-I days had > 5 mm in CHIRPS, versus 45% of reported days · incomplete days (flags A, B, C, E, H) are removed
  • GSOD max/min temperature is derived from hourly or 3-hourly reports, while TMD reads max/min thermometers directly, so GSOD can differ slightly
  • GSOD daily means are used only for days with at least 4 observations · only quality-controlled GHCNh values are used
  • Station counts change by year: GSOD 66 stations (2000) → 133 (2010) · GHCNh 46 → 101 → ~160
